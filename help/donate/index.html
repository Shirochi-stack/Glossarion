Contribute & donate

Glossarion is free, has no ads and sells nothing. It keeps going because people use it, report what breaks, and chip in when they can. Here is how you can help.

Donation

Donations pay for the API credits used to test new models and providers, and for the time it takes to keep up with them. They are always optional — every feature stays free either way.

☕ Ko-fi

One-off or monthly support, no account needed.

Community

  • Help others on Discord. Share the models and settings that work for you, prompt profiles for your language, and answers to newcomers' questions.
  • Spread the word. If Glossarion helped you read something, tell the people who might want it too.

Bug reports & ideas

Found a bug or have an idea? Open an issue on GitHub or post in Discord. The most useful reports include:

  • your Glossarion version and build (for example v9.15.13 NoCuda) and your device;
  • the model you used;
  • what you did, what you expected, and what happened instead;
  • the log from the run (and a screenshot if it's a display problem). Remove your API keys before sharing anything.

Code

Glossarion is written in Python: PySide6 for the desktop app and Flet for Android and iOS, sharing one translation backend. Pull requests are welcome — bug fixes, provider support, new file formats and documentation alike.

  1. Fork Shirochi-stack/Glossarion and clone your fork.
  2. Install the requirements and run python src/translator_gui.py (see Run from source).
  3. Make your change on a branch, run the tests in tests/, and open a pull request explaining what it does.

Past contributions include the SDLXLIFF reviewer workflow, model-specific output fixes and new provider routes — thank you to everyone who has sent one.
